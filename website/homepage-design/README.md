# IJM Worx — Homepage Design Concept

A complete, responsive homepage concept for ijmworx.com, built from the
brand-intelligence files. Open `index.html` in any browser to view it (desktop
and mobile). It's a real, working mockup — not a wireframe — and is structured so
each section can be split into a Wix HTML embed, matching your existing
"Homepage Sections" workflow.

## The strategy behind it

The homepage's one job (per `customer-journey.md`) is to turn a visitor into a
**free 3D design / estimate** request. Every section is ordered to move a nervous,
research-heavy homeowner from "wow" to "I trust these guys" to "let's talk":

| Section | Brand-brain job |
|---|---|
| **Hero** — "From Bare Dirt to Your Backyard Oasis" | Lead with the transformation outcome + the 3D hook (creator-style: outcome first, never gatekeeping). Dual CTA + trust chips up top. |
| **Trust strip** | Licensed, BBB A+, 4.9★, financing, since 2007 — answer the "are they legit?" question instantly. |
| **What We Build** | The full-service edge from `market-positioning.md` — "one team, whole backyard," pools featured (your proven demand). |
| **3D Design feature** | Your single biggest differentiator. De-risks the spend — the exact fear in `audience-delight.md`. |
| **Transformations** | "Dirt → desert oasis," real local before/afters — the #1 thing the audience shares. |
| **Why IJM** | Directly answers the ghosting fear: "crews that show up," permits handled, since 2007. |
| **Reviews** | Real quotes from your 36 reviews (Rick, Carlos, Angel). Social proof from people like them. |
| **Financing band** | "$149/mo" turns the price objection into a monthly number. |
| **Service area** | Local SEO + relevance for El Paso + the Borderland towns. |
| **Final CTA + sticky mobile bar** | One clear, low-pressure next step. Most traffic is mobile, so call/estimate is always one tap away. |

## Voice check
Every headline follows `creator-style.md`: warm, local, transformational, and
**never** the gatekeeping tone ("Serious Homeowners Only") that tested Poor. If
you could swap "IJM Worx" for any pool company and it still read, it was rewritten.

## Visual direction
- **Palette:** deep pool blue/teal (water) → warm sunset amber (the desert), on a
  clean warm-white. Evokes "pools + El Paso outdoor living" without a photo.
  - Ink `#14233b` · Water `#0e7490`/`#0c4a6e` · Sun/CTA `#e8730f` · Sand `#f7f2e9`
- **Type:** Fraunces (a warm, crafted serif) for headlines = craftsmanship;
  Inter for body = clean and legible.
- **CTAs:** the amber "Free 3D Design" button is the primary action everywhere.

> match them exactly.

## Photos to drop in (the labeled blocks)
The colored blocks are placeholders marked with what belongs there. Priorities:
1. **Hero** — a stunning finished pool at dusk (lit, with mountains/pergola).
2. **3D feature** — a side-by-side of a 3D rendering and the finished build of the *same* yard (this is the money shot).
3. **Transformations** — 3 real before/after pairs (dirt → finished).
4. **Service area** — an aerial of a completed El Paso backyard.
Use real project photos only — `audience-delight.md` is explicit that stock pushes this audience away.

## Putting it into Wix
1. Review the concept and confirm direction (colors, sections, copy).
2. Either rebuild these sections natively in the Wix editor, or split `index.html`
   into per-section HTML embeds (the pattern you already use for "Homepage
   Sections"). Each `<section>` is self-contained.
3. Wire the CTAs to your estimate form / phone, and make sure the form fires a
   conversion (see the campaign tracking checklist) so the ad traffic is measurable.
