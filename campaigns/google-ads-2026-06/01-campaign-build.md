# Campaign Build — IJM Worx Outdoor Living Search (2026-06)

Full build for a single Google Ads **Search** campaign with **8 service ad
groups**. This is the fix for the April 2026 audit finding: one ad group, pool
keywords only, 7 of 8 services invisible.

All headlines are ≤30 characters and all descriptions ≤90 characters (Google
Ads RSA limits). Display paths are ≤15 characters.

---

## Campaign settings

| Setting | Value |
|---|---|
| Campaign name | `IJM Worx - Outdoor Living Search` |
| Type | Search, "Leads" goal |
| Networks | Search only (turn **off** Search Partners and Display Expansion to start) |
| Locations | El Paso TX (+ Upper Valley, Westside, Northeast), Horizon City, Socorro, San Elizario, Canutillo, Vinton (TX), Sunland Park (NM) |
| Location option | **Presence** — "People in your targeted locations" (not "presence or interest") |
| Language | English + Spanish |
| Bidding | Start **Maximize Clicks** (learning), move to **Maximize Conversions / Target CPA ~$120** after tracking is fixed and ~15–30 conversions accrue |
| Budget | Recommend **$40–$60/day** to start across 8 ad groups; scale by service performance (SOW range $500–$1,500/mo; account has run higher) |
| Ad rotation | Optimize |
| Ad schedule | Consider business hours + early evening; flag if after-hours calls aren't answered |
| Negative keywords | Apply the shared list in `02-negative-keywords.md` |
| Assets | Apply everything in `03-extensions-and-assets.md` |

> **Final URLs:** the CSVs use `https://www.ijmworx.com/` as a safe placeholder.
> Swap each ad group to its dedicated service landing page once built — see
> `04-landing-page-briefs.md`. Pointing all ads at one generic page is the
> low–Quality-Score problem the audit flagged.

## Notes on pinning

Leave headlines unpinned so Google can optimize, with one exception: if you want
the credential always visible, pin **"Licensed & Insured Since 2007"** to
Position 1 *or* 3 in each ad group. Don't over-pin — it caps Ad Strength, and the
audit's winning ad earned "Excellent" precisely because it stayed flexible.
