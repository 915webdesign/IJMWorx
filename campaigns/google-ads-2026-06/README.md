## How to import (Google Ads Editor)
1. Open **Google Ads Editor** and download the IJM Worx account.
2. **Account → Import → From file**, choose `import/keywords.csv`, review, and apply.
3. Repeat for `import/responsive-search-ads.csv`.
4. Add negatives: create a shared list `IJM - Outdoor Living Master`, paste from
   `import/negative-keywords.csv`, and apply it to the campaign.
5. Add assets/extensions per `03-extensions-and-assets.md` (these aren't in the CSVs).
6. Work `05-tracking-and-launch-checklist.md` top to bottom **before** posting changes.
7. **Post** to the account.

> The CSVs use `https://www.ijmworx.com/` as the Final URL placeholder. Swap each
> ad group to its service landing page (`04-landing-page-briefs.md`) when built.
