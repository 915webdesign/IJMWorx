# Shared Negative Keyword List — IJM Worx Outdoor Living

Create **one shared negative-keyword list** named `IJM - Outdoor Living Master`
and apply it to the campaign. The audit found 440 negatives manually duplicated
3× across campaigns — a shared list fixes that and keeps everything in one place.

Match types below: **Phrase** blocks any search containing that wording;
**Exact** blocks only that exact query. Default to Phrase unless noted.

> **Deliberately NOT blocked:** `free` and `affordable`. IJM offers free
> estimates / free 3D design, and "affordable pergola" is good buyer intent.
> Watch the search-terms report instead of hard-blocking these.

## Ongoing management
- Review the **search-terms report weekly** for the first 6–8 weeks. Add junk as
  negatives; promote strong converting queries to their own exact-match keyword.
- Keep an eye on cross-service bleed (e.g., a "concrete" search matching the pool
  ad group) and add ad-group-level negatives to keep each theme tight.
