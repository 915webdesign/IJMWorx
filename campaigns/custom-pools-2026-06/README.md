# Custom Pools Campaign — June 2026

A new, **dedicated Google Ads Search campaign for custom pools only** for IJM
Worx. Plan + ready-to-use content, generated by the `ppc-ads` skill from the
brand-intelligence files. This is the focused, proven-converter campaign — start
here, expand to other services later.

## How to import (Google Ads Editor)
1. Open **Google Ads Editor**, download the IJM Worx account.
2. **Account → Import → From file** → `import/keywords.csv` → review → apply.
3. Repeat for `import/responsive-search-ads.csv`.
4. Negatives: create/confirm shared list `IJM - Outdoor Living Master`, then add
   the cross-service terms — or just import `import/negative-keywords.csv`
   (self-contained) into the campaign's negatives.
5. Add assets/extensions per `04-extensions-and-assets.md` (not in the CSVs).
6. Work `06-tracking-and-launch-checklist.md` **before** posting.
7. **Post** to the account.

> Final URLs are placeholders (`https://www.ijmworx.com/`). Swap to
> `/custom-pools-el-paso` once the landing page in `05-landing-page-brief.md` is built.
